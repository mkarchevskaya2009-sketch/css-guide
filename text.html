Робота з текстом

Текст — це 90% веб-інтерфейсу. CSS надає безмежні можливості для його оформлення.

1. font-size (Розмір)

Можна вказувати в px (фіксовано) або rem (адаптивно). Професіонали обирають rem.

2. font-family (Шрифти)

Дозволяє вибрати шрифт. Завжди вказуйте запасні варіанти на випадок, якщо основний шрифт не завантажиться.

ШрифтиCSS
p {
  font-family: 'Inter', Arial, sans-serif;
  font-size: 1.1rem;
  line-height: 1.6; /* Міжрядковий інтервал */
  color: #334155;
  text-align: justify;
}
Порада: Для основного тексту використовуйте line-height від 1.5 до 1.8. Це значно полегшує читання.
