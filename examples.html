Надихаючі приклади

Тут ви можете побачити, як виглядають елементи, і одразу скопіювати їх код.

1. Кнопка з ефектом підйому

.btn:hover {
  transform: translateY(-3px);
  box-shadow: 0 10px 20px rgba(0,0,0,0.1);
}

2. Ефект матового скла (Glassmorphism)

Скляна картка

.glass {
  background: rgba(255,255,255,0.2);
  backdrop-filter: blur(10px);
}

3. Ідеальне кругле фото

.avatar {
  border-radius: 50%;
  object-fit: cover;
}
