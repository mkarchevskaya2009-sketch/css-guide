Ласкаво просимо у світ стилів

CSS (Cascading Style Sheets) — це мова, яка перетворює сухий HTML-документ на привабливий веб-інтерфейс. Без CSS інтернет виглядав би як звичайна газета.

Чому це важливо?

CSS дозволяє відокремити зміст сторінки від її оформлення. Це означає, що ви можете змінити весь дизайн сайту, відредагувавши лише один файл стилів.

Три способи підключення:

  1. Зовнішній файл: Найкращий спосіб (використовуємо тут).
  2. Внутрішні стилі: Тег <style> у "голові" документа.
  3. Inline-стилі: Атрибут style="..." прямо у тегу (не рекомендується).
