Flexbox: Швидкий старт

Раніше верстка була складною. Flexbox змінив усе, дозволивши вирівнювати елементи в один рядок коду.

Головні осі:

У флекс-контейнера є головна вісь (горизонтальна) та поперечна (вертикальна).

ВирівнюванняCSS
.container {
  display: flex;
  justify-content: center; /* Центр по горизонталі */
  align-items: center;     /* Центр по вертикалі */
  gap: 20px;               /* Відстань між елементами */
}
Позиціювання: Крім Flexbox, використовують position: absolute (вільне плавання) та position: fixed (закріплення при скролі, як меню).
